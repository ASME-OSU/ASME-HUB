# Private annual handoff checklist — copy into the chapter-controlled folder

This is an empty template, not an executed run or a public place to paste private links. The coordinator creates one copy per target year and named Hub run, attaches the actual observed setup receipt or the verified installed provisioner’s `readableReceipt`, and fills every owner, time, evidence and decision. Keep the completed copy and link bundle private. The Hub progress export does not include annual-link draft fields.

Use `NOT RUN`, `BLOCKED`, `PASS` or `FAIL` for each observation. PASS requires the named holder's actual evidence on this run. Record blocked owner and next action. Prior mock results never fill a new run’s cells. In rehearsal, verify the approved test account and reviewer; in production, each incoming holder verifies their own access. Mark production-only rows NOT APPLICABLE in rehearsal rather than Passed. See [Guide 9 applicability](current-implementation.md#two-completion-decisions).
