This is an empty template, not an executed run or a public place to paste private links. The coordinator creates one copy per target year and named Hub run, attaches the provisioner's `readableReceipt`, and fills every owner, time, evidence and decision. Keep the completed copy and link bundle private. The Hub progress export does not include annual-link draft fields.
