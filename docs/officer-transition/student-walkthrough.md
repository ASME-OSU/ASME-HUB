# Student walkthrough — annual officer transition

Use one checklist for one academic year and one attempt. Practice uses private copied files; Real handoff uses the President’s approved chapter workspace. The President coordinates access, names one setup operator and provides the recovery contact. Each officer records their own checks. Never mark a review passed merely because setup says ready.

## 1. Year Selection & Access

Choose the full year, for example `2027-2028`, and Practice or Real handoff. Start a checklist or continue the existing attempt. Obtain the current private checklist and contact route from the President. Open your required tools with your own approved account. A Request access page means Blocked: save its URL and assign the access request to the President.

Before creating files, the setup operator needs three supplied values: the private parent folder where the annual folder will be created, the intended Control Center spreadsheet, and a positive approved engagement goal. The calendar iCal URL is optional; leave it blank if none was supplied. For Practice, create a private empty practice folder and copy the Control Center, retaining its twenty header columns and clearing only old data rows in the copy. Do not substitute a production Center. The setup app remembers its last workspace globally: inspect it before switching Practice/Real handoff.

## 2. One-Click Annual Setup

The **annual files** are this year’s Points Master, attendance Form, Points Export, Budget Tracker and Budget Export. The **setup summary** is a downloadable text file containing their seven links and checked settings. A **private links backup** is the separate `.json` file downloaded from the Hub, used to restore your saved links.

If the files and summary already exist, open and compare them. Do not have each officer create their own files. Otherwise the designated operator opens **Open Annual Setup** in Chrome’s ASME profile, signed in only as `asmeohiostate@gmail.com`. Open **Chapter setup — save once**, inspect/save the supplied values, then enter the same academic year as the Hub and run once. Google services may require the owner’s authorization.

Keep the page open. If the response-tab message says retry, use the same year and unchanged workspace/Center; retry resumes the saved run. Do not rename/delete copies or change workspaces to overcome this message. A successful run shows seven links and **Download setup summary**. Download it. Setup creates six folders (annual parent plus five subfolders) and five working files; the Form editor and respondent URLs are two views of the same file.

Paste the seven summary links into the Hub’s saved links, also set **Private mock Control Center** to your copied Center in Practice, and save them on this device. The downloaded `.txt` summary is readable evidence; **Import automation links** expects a separate Hub private links backup (.json). Download the Hub private links backup after saving the links. Fill the summary’s Hub run/contact placeholders from the President’s instructions.

Compare the Form’s **Responses → View in Sheets** destination with the summary and Points **Config B7**. Google chooses the response-tab name; an older empty response tab may remain from the template. Do not guess a tab by its number. Confirm Points **Config B5 = TESTING**, the Form is closed, and the copied Control Center row is inactive/noncurrent. A completed retry must return the same files and state; it should not reset files that are already LIVE.

## 3. Export Access & Test Check-in

**Real handoff:** review actual event settings, approved finances, bank reconciliation, both export imports and the maintainer’s dated readiness record. Use existing test evidence or create a separate set of Practice files for the exercises below. Do not enter fictional attendance or transactions in real working files. Missing evidence is Blocked and assigned to the maintainer.

**Practice only:** the following mock events, five submissions, sample budget and status-switch exercise all take place in your isolated practice copies.

Open the copied Points Master README. Enter only yellow input cells. In **Events**, create a `MOCK Fall` General Body Meeting dated in the selected Fall (5 points) and a `MOCK Spring` Technical Workshop dated in the selected Spring (8 points). IDs, term, year and points calculate automatically. Enable scoring and `form_open` for both.

Choose **ASME Tools → Enable automatic event sync** once in this annual copy. Complete owner authorization if requested. Edit a mock event name through Sheets, keeping its `MOCK` prefix, and confirm the copied Form’s Event ID dropdown changes; this proves the trigger ran. API edits alone do not exercise an edit trigger. **Sync Events to Google Form** is the manual retry/fallback; it preserves intake state.

Before intake, use the Form’s **Publish → Manage responders** and restrict responder access to the approved testers. A copied Form may be unpublished. Publish the private practice Form, explicitly enable **Accepting responses** for the approved testers, and open the respondent link to confirm the questions are available; publishing and intake are separate. Do not distribute the practice link. Use two fictional name.numbers consistently (for example `rehearsala.999` and `rehearsalb.999`). A first profile must fill every required field. Use the actual displayed Yes/No labels.

Submit these five cases in this order using the respondent link and **Submit another response** between cases:

| 1 | A | Yes; complete profile | MOCK Fall | 5 |
| 2 | A | No | Same MOCK Fall | 0; duplicate exception |

Verify five arrivals in the summary’s actual response tab and no new rehearsal rows in other response tabs. Close Form intake, set both `form_open` checkboxes FALSE, and sync. Reload the respondent URL and confirm responses are closed. Keep scoring definitions for evidence until cleanup review.

Open both exports and authorize only their matching copied source workbooks from the summary. Import access can expose the source to editors of the destination; keep both practice files private. For the fictional plan, set Funding Setup B5:D5 to 100, 0, 0 and B6:D6 to 0, 0, 0; B8 to `None — MOCK rehearsal only`; Category Budgets B5 to 100 with the other B5:C18 allocations zero. Confirm both Category Budgets B23:C23 differences are zero, then check Funding Setup B10 for this mock review. Run **ASME Tools → Run Pre-Flight Sanity Check** and save its actual report. Preflight checks wiring; it does not substitute for these submissions, import permissions, funding approval or owner sign-off. If results differ, record Blocked with the observed result and assign the technical maintainer.

## 4. Communications & Calendar

Open **Newsletter Builder** from Step 4. In **Calendar**, enter the full year and choose **Load fictional Fall/Spring**; check both semesters and the **FICTIONAL REHEARSAL** label. When finished, choose **Remove fictional events → Upcoming**. Repeat the preview on the **Public Events Calendar** generated list, using **Upcoming dates** after removal. Its embedded Google calendar is a separate live view.

In Real handoff, compare approved live calendar and communications records and save the approved draft. The fictional preview and MOCK newsletter below belong only to Practice. Use a clearly labeled MOCK newsletter in Practice. Export the existing draft before edits. Load the local fictional Fall/Spring calendar preview for the selected year, check Desktop/Mobile, and remove fictional events when finished. This does not create Google calendar events. Compare real dates, times, time zones and locations only against approved chapter records. The President supplies sender, reply-to, full postal address, annual links and dated statistics; missing approval stays Blocked. Save a draft; do not send a practice issue.

Keep three distinct backups: Hub **Export progress**, Hub **Download private links backup**, and Newsletter **Templates → Export Draft .json**. Follow the [three-file recovery procedure](recovery-practice.md) to restore them in a separate browser profile and compare the fields. A downloaded file alone is not restoration evidence.

## 5. Activation & Go-Live

Practice ends with Points TESTING, Form intake closed, all event `form_open` FALSE, and settings inactive/noncurrent. Record activation **Skipped — Rehearsal only**. Preserve evidence or perform reviewed cleanup; do not activate practice files.

For MOCK attendance cleanup, use **ASME Tools → Clear Test Data**. Review counts before agreeing. It requires the exact linked annual Form/tab and closed TESTING state, creates and verifies a private archive, then removes reviewed Form response IDs and corresponding raw rows. Google Form response IDs cannot be restored; the owner must approve permanent removal. Cancel to retain evidence. This menu does not remove mock event definitions, adjustments or budget inputs: review their input cells separately and preserve formula columns. Mixed real/unmarked attendance stops cleanup. If the menu is missing, reload once; older copies require a maintainer update because later template code does not propagate to existing copies.

Real activation requires recorded incoming acceptance, required reviews, actual funding/reconciliation and coordinator launch approval. The authorized settings owner then changes Points LIVE and the verified real Control Center year active/current at the approved time, retires the old current-year flag and checks the intended intake state. An unresolved review means no launch. The student never has to guess an approval: record the missing item, owner and next action.

## Progress and starting again

The progress bar counts passed reviews and completed steps. Choosing Next step only moves between instructions. A blocked or failed item does not advance the bar. In Practice, the final activation skip counts only after the required practice reviews pass.

To start again, choose **Reset checklist progress**, read the named checklist and year, then choose **Start fresh checklist**. This starts with no results or notes and carries over only the links already saved. Your previous checklist remains under **Choose or change checklist → Saved checklist for this year**; select it and choose **Continue checklist** to return to it. Unsaved edits do not carry over. This does not create Google files, change the active year, or grant launch approval.
